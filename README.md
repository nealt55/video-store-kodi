# Video Store Kodi Skin

Retro neon VHS rental-store Kodi skin based on Arctic: Zephyr – Reloaded.

- **Addon ID:** `skin.video.store`
- **Project version:** `1.0.0`
- **Target:** Kodi Omega
- **Base:** Arctic: Zephyr – Reloaded 3.0.3 codebase

The build system downloads the pinned upstream skin source, applies the Video Store customisations, and creates the Kodi skin ZIP.

Version checks are enforced during the build so `addon.xml`, the ZIP filename, and repository metadata cannot silently disagree.
